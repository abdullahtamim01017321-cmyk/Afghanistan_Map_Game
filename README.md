# 🇦🇫 Afghanistan Provinces Guessing Game

### 🐍 Python | Pandas | Turtle Graphics | 100 Days of Code

Welcome to the **Afghanistan Provinces Guessing Game**, an interactive educational Python project designed to help people discover, learn, and remember the 34 provinces of Afghanistan.

This project was inspired by **Day 25 of Dr. Angela Yu's 100 Days of Code: The Complete Python Pro Bootcamp**.

Instead of building the original U.S. States Guessing Game, I decided to create a version dedicated to my home country, **Afghanistan**. 🇦🇫

My goal is to combine programming, education, and geography into an enjoyable learning experience.

---

Afghanistan is a country with a rich history, diverse cultures, beautiful landscapes, and 34 provinces.

However, remembering the names and geographical locations of every province can be challenging.

**Learn Python. Explore Afghanistan. Challenge Your Knowledge!**

## 🎮 How the Game Works

The game presents a map of Afghanistan and challenges players to identify its provinces.

The gameplay follows a simple process:

1. The game displays a map of Afghanistan.
2. The player enters the name of a province.
3. Python checks whether the entered name matches a province in the dataset.
4. Correctly guessed provinces are identified on the map.
5. Players continue discovering provinces and improving their geographical knowledge.

The ultimate challenge is to identify all **34 provinces of Afghanistan**.

## 🚀 How to Run the Project

### Step 1: Install Python

Install Python 3 from the official website:

https://www.python.org/

### Step 2: Download the Project

Download the repository as a ZIP file and extract it, or clone the repository using Git.

### Step 3: Install Dependencies

Open a terminal inside the project folder and install Pandas:

```bash
pip install pandas
```

Turtle is generally included with standard Python installations that support Tkinter.

### Step 4: Run the Game

Make sure the required map image and CSV data files are in their expected locations.

Run the main Python file:

```bash
python main.py
```

The game window should open, allowing you to start exploring Afghanistan's provinces.
